端智能日报 2026-05-16

本期聚焦：Google I/O 倒计时3天，广告×AI的两条主线同步推进——OpenAI ChatGPT Ads 在两周内完成"企业级→自助→全球化→受众定向"四级跃升，Custom Audiences 昨日曝光标志着对话式 AI 广告进入"数据资产定向"时代；Apple Core AI 替代 Core ML 的 iOS 27 框架重构（WWDC June 8）则将决定 iOS 端侧推理的开发者能力边界，两者共同勾勒出后 ATT 时代广告技术栈的两种演进路径。

1. 【OpenAI ChatGPT Ads Manager: Custom Audiences 功能曝光 + 5国国际扩张，对话式 AI 广告"受众定向"能力首次开放】

  • 评分：A/4 · I/4 · S=12 · P0 · 价值类型：新能力探索 / 收入提升
  • 来源：Axios | OpenAI launches self-serve ad platform | 2026-05-05；PPC Land | OpenAI adds custom audiences to ChatGPT ads | 2026-05-14；Digiday | OpenAI offers ChatGPT ads to new markets | 2026-05-07

内容总结（~140 字）： 5月14日，广告主 Juozas Kaziukenas 在 LinkedIn 曝光 ChatGPT Ads 的 Custom Audiences 功能截图——广告主可上传原始或 SHA-256 哈希化邮箱/手机号，实现精准受众触达或定向屏蔽，这是 ChatGPT 广告从"纯情境定向"首次引入"第一方数据定向"。结合 5 月 5 日移除 $50K 最低门槛的自助式 Ads Manager 上线（同步新增 CPC 竞价模式），以及 5 月 7 日向英国、日本、韩国、巴西、墨西哥 5 国扩张，OpenAI 广告生态在两周内完成四级跃升。技术架构：广告以"AI 回答后附带"模式呈现（不影响回答本体），情境定向（当前对话主题 + 历史聊天语境）+ Custom Audiences 双轨并行；合作生态对接 Dentsu / Omnicom / WPP / Adobe / Criteo 等。财务目标：2026年广告收入 $25 亿，2030年目标 $1000 亿。

业务价值与适配性： 可以让我们在 ChatGPT 平台上以"对话情境精准匹配 + 第一方数据受众过滤"双轨模式投放音频/内容流媒体广告，直接覆盖"正在讨论音乐订阅/视频套餐"的高意图用户。可直接应用：建议立即评估 ChatGPT Ads Manager 注册并测试音频广告库存——Custom Audiences 的 hashed email 上传机制与现有 DMP 资产天然衔接，优先验证"现有用户召回"和"高价值用户排除"两类场景；情境定向的 plain-language context hints 设计逻辑（以自然语言描述目标对话场景而非关键词）值得引入端侧广告上下文特征工程的设计参考。

2. 【Apple Core AI 正式替代 Core ML（WWDC June 8，23天倒计时）：端侧推理开发者框架重构，iOS 27 首次开放生成智能 API】

  • 评分：A/3 · I/4 · S=10 · P1 · 价值类型：新能力探索 / 成本优化
  • 来源：9to5Mac | Apple replacing Core ML with modernized Core AI framework for iOS 27 at WWDC | 2026-03-01；AppleMagazine | Apple Core AI: How iOS 27 Signals a New Developer Framework at WWDC 2026 | 2026-05；WWDC 2026 官方 | WWDC26 Returns June 8 | 2026-05

内容总结（~140 字）： iOS 27 将以全新 Core AI 框架取代沿用十年的 Core ML，预计在 WWDC June 8 主题演讲正式发布 API 规格。核心变化：① 框架统一——Core AI 整合原 Core ML（传统 ML 推理）与 Apple Intelligence 后端（端侧 LLM/扩散模型），第三方 App 通过统一 API 调用；② 新推理接口——iOS 27 预计开放"本地模型直接调用"hook，App 可在设备内运行小模型而无需路由至 Gemini 或 Private Cloud Compute，降低多跳延迟；③ Siri Extensions 系统——允许 Siri 与 Claude、Gemini 等第三方 AI 协同完成多步骤任务；④ 平台范围——iOS 27 / iPadOS 27 / macOS 27 / watchOS 同步；⑤ Create ML 配套升级。Siri 2.0：LLM 驱动重构，Dynamic Island 集成，支持跨 App 多步骤 Agent 任务。

业务价值与适配性： 可以让我们在 iOS 27 上以 Core AI 统一接口直接调用设备本地 LLM 能力，在广告 SDK 内实现毫秒级端侧意图识别与广告策略调度，无需云端 LLM 调用的网络延迟和合规成本。关键判断：若 Core AI 提供开放的"本地模型槽"（允许第三方小模型注册），广告 SDK 可植入自有蒸馏模型，实现比任何现有 iOS 方案更低延迟的端侧 CTR 特征推断；若仅开放 Apple Intelligence 输出，则降级为"获取更结构化系统意图信号"。适配性评估节点：6 月 8 日 WWDC 后 48 小时内完成 Core AI vs Core ML API 差异审查，确认是否开放第三方模型注册能力。

3. 【Qualcomm × 长鑫存储（CXMT）3D DRAM 独立 NPU：稳定 40 TOPS + 4GB 堆叠内存，突破移动 AI 长时推理内存瓶颈】【延迟发酵】

  • 评分：A/2 · I/3 · S=7 · P2 · 价值类型：新能力探索
  • 来源：快科技 | 高通、长鑫合作细节曝光！联手打造手机独立NPU | 2026-04；SemiWiki | Qualcomm and CXMT jointly launch a standalone NPU + 3D DRAM | 2026-04；Intelligent Living | Qualcomm and CXMT's 3D DRAM NPU | 2026-04

内容总结（~130 字）： 高通联合长鑫存储（CXMT）和兆易创新（GigaDevice）开发手机独立 NPU + 3D DRAM 方案，与主 SoC 解耦，专攻持续 AI 推理。核心指标：① 独立 NPU持续稳定输出约 40 TOPS，相较骁龙 8 Elite 峰值 100 TOPS 但实际受热节流影响，独立设计可在长时任务（实时视频翻译、后台图像生成）中维持算力稳定性；② 4GB 3D DRAM（TSV + Hybrid Bonding 封装），带宽超越 LPDDR5X，彻底消除当前端侧 LLM 推理的内存带宽瓶颈（移动端约 90 GB/s 带宽是限制上下文长度的核心约束），可将端侧可用上下文从约 8K token 扩展至 32K+；③ 目标市场：2026年底/2027年初量产，定位国内 4000-4500 元安卓机型。挑战：内存成本上涨 + 商业模式不明朗，首批客户数低于预期。

业务价值与适配性： 可以让我们在搭载该 NPU 的安卓旗舰上实现"长视频内容实时语义理解 + 长时广告意图跟踪"等对内存带宽敏感的端侧推理任务，当前内存墙是制约端侧广告模型上下文长度的核心瓶颈，4GB 3D DRAM 若量产将从硬件层解除这一限制。暂不适用（时间窗口原因）：量产周期为 2026 Q4-2027 Q1，现阶段核心价值在于确认高通的端侧 AI 战略方向——建议 2026 Q3 量产确认后将该 NPU 纳入广告 SDK 旗舰档位性能规划，并评估是否需要为"32K+ 上下文端侧模型"预留 API 接口设计空间。

其他观察

今日三条信号描绘出一幅"广告×端智能"在 Google I/O 前夜的分叉路口图景：① 云端广告入口重构——ChatGPT Ads 以情境定向 + Custom Audiences 建立了与传统 DSP 平行的全新广告分发范式，AI 对话成为新的广告曝光单元；② 端侧开发者框架换代——Apple Core AI 替代 Core ML 意味着 iOS 上的推理能力边界将在 WWDC 重新划定，第三方广告 SDK 能否直接调用本地 LLM 是最关键的悬念；③ 硬件算力底座升级——Qualcomm 独立 3D DRAM NPU 锁定 2027 年的安卓旗舰算力基线，32K+ 上下文的端侧推理将从"实验室可行"变为"旗舰机标配"，广告模型的上下文建模窗口有望随之扩大。今日端侧广告相关的直接落地内容较少（除 Item 1 的 ChatGPT Ads），这与 Google I/O 前三天的"信息真空期"规律一致。
