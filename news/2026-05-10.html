端智能日报 2026-05-10

本期聚焦：OpenAI Ads Manager 自助广告平台全面开放，LLM 意图理解正式进入广告主流链路，重塑效果广告竞争格局；Google I/O 2026（5/19）倒计时 9 天，Android AI Core 第三方 API 零成本本地推理细节明确，端侧广告基础设施窗口期临近。

1. 【OpenAI 自助广告平台（Ads Manager）正式开放：LLM 意图广告全面进入效果市场，$100M ARR 已验证】

  • 评分：A/4 · I/5 · S=13 · P0 · 价值类型：新能力探索 / 收入提升
  • 来源：OpenAI / Axios | OpenAI launches self-serve ad platform | 2026-05-05

内容总结（~130 字）： OpenAI 于 5 月 5 日在美国开放 Ads Manager 自助广告平台，允许广告主直接在 ChatGPT 内创建和管理广告活动。平台支持 Dentsu、Omnicom、WPP 等 DSP 代理商及 Adobe、Criteo、Kargo、Pacvue、StackAdapt 等 Ad Tech 合作方接入。4-5 月更新引入「站点像素 + Conversions API 服务端归因」，补齐了效果营销侧所需的转化度量能力。广告主目标人群：ChatGPT 800M 周活用户，触达入口为对话式问答场景（intent-native）。已验证信号：$100M+ 年化收入，2 个月内达成，高于 OpenAI 原预期节奏。

业务价值与适配性： 可以让我们在「品牌内容 + 意图触达」场景下把 ChatGPT 作为第三方广告渠道纳入流量组合，尤其对 LTV 高、决策周期长的品类（如金融、汽车、旅游）具有直接预算转移价值。可直接应用：建议短期在渠道评估矩阵中加入 ChatGPT Ads；中期跟踪 intent-based CTR 数据，反哺端侧用户意图模型训练样本质量评估。

2. 【进展更新】【Google I/O 2026（5/19）：Android AI Core 第三方 API 零 Token 成本 30-50ms 本地推理 + Gemini 4 发布确认——端侧广告推理栈进入最终技术选型窗口】

  • 评分：A/3 · I/5 · S=11 · P0 · 价值类型：新能力探索 / 成本优化
  • 来源：Android Authority / Google I/O 官网 | What to Expect from Google I/O 2026 | 2026-05-09
  • 相较 2026-05-07 报道新增：明确 30-50ms 本地推理 SLA + 零 per-token 成本模型；Gemini 4 发布锁定；Android XR 生态加入

内容总结（~120 字）： Google I/O 2026 于 5 月 19 日开幕（Mountain View），Android 17 将随大会正式发布。核心工程信息：Android AI Core 的第三方开放 API 将支持 30-50ms 端侧本地推理，无需网络、无 per-token 成本，适合对延迟敏感、频繁调用的场景。Gemini 4 大模型将于大会首次亮相，主题集中于"Agentic AI"多步骤任务规划。此外，Android XR（智能眼镜 OS）也将正式亮相，MediaTek Dimensity 9600 配套 SDK 同步更新。The Android Show（5/12）将于 2 天后率先预热 Android 17 功能细节。

业务价值与适配性： 可以让我们在广告 SDK 内直接调用 Android AI Core 端侧模型做轻量级用户意图分类，无 API 费用、无离线风险，30-50ms 满足广告请求前置推理时序。可直接应用：建议在 5/19 后立即接入 Android AI Core API DP，测试端侧 Gemini Nano 3 做广告 pre-rank 特征抽取的可行性；WWDC（6/8）Apple Core AI 同类 API 对照研究同步启动。

3. 【LiteRT × Qualcomm/MediaTek NPU 双线量产落地：FastVLM 0.12s TTFT + Google Meet 25× 大模型上线——端侧视觉推理进入工业生产级】

  • 评分：A/3 · I/4 · S=10 · P1 · 价值类型：成本优化 / 用户体验
  • 来源：Google Developers Blog | Unlocking Peak Performance on Qualcomm NPU with LiteRT · MediaTek NPU and LiteRT | 2026

内容总结（~140 字）： Google Developers Blog 连续发布 Qualcomm 和 MediaTek 双路 NPU + LiteRT 生产落地报告。Qualcomm 侧：LiteRT TF 2.21（2026-03 GA）在 Snapdragon 8 Elite Gen 5 上使 56 款模型推理 <5ms；FastVLM 场景理解模型实测 TTFT 0.12s、prefill 11,000 tokens/s、decode >100 tokens/s（INT8/INT16 量化，全 NPU 路径）。Google Meet 成功将 Ultra-HD 背景分割模型扩大至原来 25× 参数量，同时维持延迟不变，系利用 NPU 异构路径实现。MediaTek 侧：Gemma 3n E2B 在 Dimensity NPU 上 prefill 1,600+ tokens/s，速度达 CPU 的 12×、GPU 的 10×，LiteRT NeuroPilot 加速器已向所有开发者开放。

业务价值与适配性： 可以让我们在创意素材理解（图文分类、视频帧分析）场景下以<5ms NPU 延迟替代当前云端 API 调用，大幅降低素材理解成本。可借鉴思路：Google Meet 的「25× 参数扩张 + NPU 保延迟」部署模式，可用于在广告排序特征塔侧尝试更大的多模态 embedding 模型而不牺牲请求延迟；Qualcomm AI Hub 模型库可作为广告端侧特征抽取模型的起点。

4. 【Apple WWDC 2026（6/8-12）：Core AI 正式替代 Core ML——iOS 27 端侧 LLM/扩散模型开发者 API 即将开放，29 天倒计时】

  • 评分：A/3 · I/4 · S=10 · P1 · 价值类型：新能力探索
  • 来源：9to5Mac / AppleInsider | Apple replacing Core ML with modernized Core AI framework | 2026-03-01（持续发酵中）

内容总结（~130 字）： Apple 将在 WWDC 2026（6 月 8-12 日）正式发布 Core AI 框架，取代自 2017 年起使用的 Core ML，标志 Apple 端侧 AI 技术栈的代际切换。Core AI 新增对 LLM 和扩散模型的原生支持，提供「在设备上运行大型语言/生成模型」的标准化开发者 API；Foundation Models API 将获得更大上下文窗口、更完善的 fine-tuning 支持。iOS 27 同步开放 Writing Tools 的 Gemini/Anthropic 第三方模型接入（Extension 机制，已于 5/9 日报道）。Create ML 和 Core ML 将并存过渡期，代码兼容性已声明保证。

业务价值与适配性： 可以让我们在 iOS 广告 SDK 中用 Core AI 替代现有的 CoreML 端侧推理调用，获得更优的 LLM 推理性能和统一的开发体验。可借鉴思路：关注 Core AI 的私有化 fine-tuning API（若开放），有望用于在设备上做广告 user persona 的本地增量更新，实现"不离开设备的用户建模"；建议在 WWDC 后 1 周内启动 Core AI 技术评估。

5. 【《人工智能终端智能化分级》国家标准 GB/Z 177—2026 发布：L1-L4 四级体系正式确立，华为/小米/OPPO/vivo 联合起草】

  • 评分：A/2 · I/4 · S=8 · P1 · 价值类型：新能力探索 / 成本优化
  • 来源：工业和信息化部 / IT之家 | AI 终端智能化分级国标出炉 | 2026-05-08

内容总结（~120 字）： 工信部、市场监管总局、商务部联合发布 GB/Z 177—2026 系列国家标准，正式建立 AI 终端智能化分级体系。"2+N"架构：L1（响应级）→ L4（协同级），其中 L4 要求端侧完整 LLM + 端云协同能力。首批覆盖手机、PC、智能眼镜、电视、汽车座舱、音箱、耳机七大品类。标准由小米、华为、荣耀、OPPO、vivo、联想、科大讯飞等联合起草。工程意义：L4 级设备需具备端云任务分发能力，明确了 NPU 算力和内存的最低门槛。

业务价值与适配性： 可以让我们用 L1-L4 设备分级作为广告定向维度，在 L3/L4 设备上启用更复杂的端侧广告策略（实时用户意图推理、端侧重排序），在 L1/L2 设备上降级为轻量化策略。可借鉴思路：将国标分级映射至广告 SDK 的端侧能力检测逻辑，避免在低端设备上触发高成本端侧推理，实现性能与成本的分层管理。

6. 【百度文心 5.1（ERNIE 5.1）发布："Once-For-All" 弹性训练，1/3 参数量 + 6% 预训练成本实现搜索榜单国内第一】

  • 评分：A/2 · I/4 · S=8 · P2 · 价值类型：成本优化
  • 来源：百度 / 新浪科技 | 百度文心大模型5.1发布 | 2026-05-09

内容总结（~120 字）： 百度发布文心大模型 5.1，基于文心 5.0 知识蒸馏，提出"Once-For-All"弹性训练框架：在单次预训练中联合优化多个具有不同深度、MoE 专家容量、路由稀疏度的子模型，总参数压缩至文心 5.0 的约 1/3，激活参数约 1/2，预训练成本降至业界同规模模型的 6%。LMArena 搜索榜 1223 分，国内第一、全球第四。已在百度千帆平台和文心一言官网同步开放，5 月 13-14 日百度 AI 开发者大会将披露更多工程细节。暂无端侧部署信息，定位云端推理。

业务价值与适配性： 可以让我们以极低成本（6% of SOTA 预训练成本）参考"Once-For-All"训练范式，在广告精排模型中探索「单次训练 → 多设备规格子模型」的部署策略，实现旗舰设备用大子模型、中低端设备用小子模型，无需分别训练。暂不适用（端侧）：文心 5.1 当前为云端模型，端侧迁移路径未明；等待 5/13-14 开发者大会披露端侧蒸馏细节后再评估。

其他观察

本周信号集中于"端侧推理生产化"与"广告新渠道"两条主线：LiteRT NPU 双芯片路径（Qualcomm + MediaTek）均已验证量产，端侧视觉推理（<5ms / TTFT 0.12s）突破了素材理解的延迟约束；OpenAI 的 Ads Manager 则标志着 LLM 意图广告进入效果市场竞争阶段，intent-based 投放思路将加速影响业界对移动端用户意图模型的需求优先级。
