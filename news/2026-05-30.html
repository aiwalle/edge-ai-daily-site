1. 【OpenAI ChatGPT 广告平台自助投放 Ads Manager 正式启动，Conversions API 开放】【延迟发酵】

  • 评分：A/4 · I/4 · S=12 · P0 · 价值类型：收入提升 / 新能力探索
  • 来源：OpenAI / Axios | openai.com/index/testing-ads-in-chatgpt | 2026-05-05（自助平台启动）/ 2026-05-07（国际扩张）

内容总结（~130 字）： OpenAI 于 5 月 5 日正式开放 ChatGPT 广告自助购买平台（Beta），核心能力：① CPC + CPM 双竞价模型（原仅 CPM），无最低消费门槛；② Measurement Pixel + Conversions API 开放——广告主可直接追踪归因，闭环效果衡量链路；③ 5 月 7 日宣布国际扩张至英国、墨西哥、巴西、日本、韩国。广告形态：在 ChatGPT 答案下方展示赞助卡（名称、标题、图、链接），答案生成逻辑不受广告干预。OpenAI 目标 2026 年广告营收 $25 亿，2030 年 $1000 亿。

业务价值与适配性： 可以让我们在音频/流媒体用户对话式广告领域，将 ChatGPT Ads 纳入投放 mix，用 Conversions API 打通端到端归因；该 API 范式与 Meta CAPI / Google Enhanced Conversions 高度同构，现有归因基建可复用。适配性判断：可直接应用——建议优先接入 Conversions API，同步评估 ChatGPT 用户（高购买力、高决策意愿）与音频用户的画像重叠度，再决定投放预算分配。

2. 【Google LiteRT 生产全面 GA + LiteRT-LM Gemma 4 MTP 3× 解码加速，NPU 百倍于 CPU】

  • 评分：A/3 · I/4 · S=10 · P1 · 价值类型：成本优化 / 新能力探索
  • 来源：Google Developers Blog | developers.googleblog.com/blazing-fast-on-device-genai-with-litert-lm/ | 2026-05-28（LiteRT GA）/ 2026-05-19（Google I/O LiteRT-LM 更新）

内容总结（~140 字）： 5 月 28 日，Google 宣布 LiteRT 高级加速能力正式进入生产版（GA）。核心数字：① GPU：ML Drift 下一代 GPU 引擎，全平台支持 OpenCL / OpenGL / Metal / WebGPU，比 TFLite 快 1.4×；② NPU：加速比可达 CPU 的 100×；③ 覆盖 Android / iOS / macOS / Windows / Linux / Web。LiteRT-LM（LLM 子框架）：Gemma 4 Multi-Token Prediction（MTP）支持，移动端 GPU 解码速度提升 3×（零质量损失）；Android 52 tokens/sec、iOS 56 tokens/sec；NPU 后端新增 CLI + Python API。生产部署：Chrome、Chromebook Plus、Pixel Watch 已跑 Gemini Nano。MediaTek Dimensity NPU 运行 Gemma 3n：prefill 1600+ tokens/sec，decode 28 tokens/sec（4K context）。

业务价值与适配性： 可以让我们在端侧广告 CTR 轻量模型 + 素材理解场景中，将现有 TFLite 模型无缝迁移至 LiteRT（接口兼容），立即获得 1.4× GPU 加速；MTP 对广告候选词生成等 LLM 任务吞吐提升显著。适配性判断：可直接应用——LiteRT GA 提供稳定 API；建议优先评估 Qualcomm Hexagon + LiteRT 路径，将 CTR 特征提取模型延迟从 CPU 百毫秒级降至 NPU 个位数毫秒。

3. 【OpenAI AI 手机：MediaTek Dimensity 9600 双 NPU 定制，端云分层推理架构，2027 H1 量产】

  • 评分：A/3 · I/3 · S=9 · P1 · 价值类型：新能力探索
  • 来源：The Next Web / wccftech | thenextweb.com/news/openai-qualcomm-ai-phone-agents-replace-apps | 2026-05-05

内容总结（~120 字）： （注：本条为 OpenAI AI 手机（智能手机形态），有别于 2026-05-28 已报道的 OpenAI io 无屏设备。）供应链报道：OpenAI 选定 MediaTek Dimensity 9600 定制版，工艺 TSMC 2nm（N2P）。核心架构：① 双 NPU 设计——轻量任务（上下文感知、记忆管理、小模型推理）在端侧 NPU 执行，复杂推理 fallback 至云端；② LPDDR6 + UFS 5.0 缓解内存瓶颈；③ 增强 HDR pipeline 支持视觉理解；④ pKVM + inline hashing 保证安全隔离。目标：2027 H1 量产，2028 年年出货 3–4 亿台。配件商 Luxshare 独家制造。

业务价值与适配性： 可以让我们在端云广告决策分层的产品规划中，将双 NPU 架构视为行业硬件演进标杆——端侧专职做轻量上下文/频次/隐私计算，云侧专职做复杂 CVR 精排。适配性判断：战略预判——可参考该架构规划广告 SDK 的端 NPU 能力边界（<5ms 轻量推理），2027 H1 设备量产后验证。

4. 【2-bit 指令微调 LLM 渐进量化：统一块级 PTQ 与蒸馏 QAT 联合框架】

  • 评分：A/3 · I/3 · S=9 · P1 · 价值类型：成本优化
  • 来源：arXiv | arxiv.org/abs/2506.09104 | 2026-05 末（近日）

内容总结（~110 字）： 论文提出统一框架，将块级 PTQ（Block-wise Post-Training Quantization，免微调、快速部署）与蒸馏驱动 QAT（Quantization-Aware Training，精度高）渐进式融合，目标是让指令微调 LLM 在 2-bit 精度下实现可用部署。2-bit 为端侧最激进的压缩方向（模型体积较 FP16 压缩约 8×），但通常精度损失严重。该方案核心：先用块级 PTQ 快速压缩至 2-bit，再以知识蒸馏在 QAT 阶段恢复精度，两阶段互补，大幅节省全量 QAT 训练成本。具体 benchmark 数据待论文开放后确认。

业务价值与适配性： 可以让我们在端侧排序轻量 LLM 头场景中，将候选模型（<3B 指令微调 backbone）压缩到 2-bit（3B FP16 ≈ 6GB → 2-bit ≈ 750MB），使旗舰机端侧运行成为可能。适配性判断：可借鉴思路——代码/模型尚未发布，建议跟踪开源时间线并与现有 INT4 方案对比精度-延迟 trade-off，评估能否替换现有 CTR 模型的 embedding lookup 层。
