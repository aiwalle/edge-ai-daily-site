端智能日报 2026-05-24

本期聚焦：广告推荐端侧落地双主线——快手 UxSID 以 Semantic ID 语义路由实现超长行为序列 O(1) 在线检索，400M 用户广告平台 A/B 验证 +0.337% 营收；百度从模型压缩工程侧、独立团队从 eCPM 价值对齐侧，同步推进 LLM 广告全链路生产化。端云协同路由与超长序列压缩的算法栈正在快速收敛。

1. 【UxSID：Semantic ID 语义路由解锁超长序列建模 O(1) 在线检索，快手广告 +0.337% 营收 +0.16ms 延迟】

  • 评分：A/5 · I/4 · S=14 · P0 · 价值类型：收入提升
  • 来源：快手技术 | arxiv.org/abs/2605.09040 | 2026-05-09（修订 2026-05-13）

内容总结（100-150 字）： UxSID 提出第三条超长序列建模路径：以目标物品的 Semantic ID（SID）作为语义路由键，索引离线压缩的用户兴趣记忆 (UID, SID)，在线推理降至 O(1)。核心双层注意力：①先以 item-agnostic 全局聚合提取通用兴趣，②再以目标 SID 做语义特定精查，生成 target-aware 偏好 embedding，完全离线预计算，在线仅读表。部署于快手 400M 用户广告平台（2026 年 4 月 1-7 日 A/B），营收提升 +0.337%，额外在线延迟仅 +0.16ms，已通过工业级流量与延迟约束双重验收。

业务价值与适配性： 可以让我们在超长用户行为序列场景（历史 clicks/purchases 数万条）下做到：以 SID 路由替代全序列 attention，将端侧或在线召回的用户表征延迟压缩至 <1ms 级别，直接支撑实时 CTR/CVR 预估。可直接应用：SID 路由范式与现有 DIN/DIEN 架构兼容，建议先在广告用户历史行为模块替换检索层；与 5/21 GenLI 的生成兴趣建模互补，两者可组成"压缩检索 + 生成融合"双引擎用户建模流水线。

2. 【Efficient LLM-based Advertising（百度）：自适应分组量化 + 层级稀疏化 + 前缀树并行验证，LLM 广告推理显著提速】

  • 评分：A/5 · I/3 · S=13 · P0 · 价值类型：成本优化/收入提升
  • 来源：百度 | arxiv.org/abs/2605.11582 | 2026-05-12

内容总结（100-150 字）： 百度团队针对 LLM 部署于实时广告系统的延迟与算力瓶颈，提出 Efficient Generative Targeting 框架，三层加速：① 层自适应分组量化（layer-adaptive group-wise quantization）：按层重要性差异化量化精度，针对 GEMV 计算场景优化位宽；② 层级半结构化稀疏化（hierarchical semi-structured sparsity）：保持硬件友好稀疏格式，大幅降低 decode 阶段 FLOPs；③ 前缀树并行验证（prefix-tree parallel verification）：类推测解码思路，并行验证多条候选生成路径，提升有效吞吐量。在两个真实广告场景（ad creative 生成 + targeted advertising）验证，实现"显著提速 + 可接受质量损耗"，工程可操作性已验证。

业务价值与适配性： 可以让我们在广告 LLM 化改造中做到：不更换模型架构的前提下将 decode 延迟降低至实时竞价（<100ms）可用区间，同时控制精度损失在业务可接受范围内。可借鉴思路：三层加速组合（量化 + 稀疏 + 并行验证）可作为内部广告 LLM 部署的基线方案，层自适应量化比全局统一量化更适合广告打分模型（不同 layer 对 eCPM 贡献差异大）；建议优先在素材理解/creative 生成链路试点，该链路延迟容忍度较竞价侧更高。

3. 【UniVA：eCPM 感知强化学习 + 商业 SID 分词器——生成式推荐首次对齐工业广告价值信号】

  • 评分：A/5 · I/3 · S=13 · P0 · 价值类型：收入提升/新能力探索
  • 来源：arXiv | arxiv.org/abs/2605.05803 | 2026-05-07

内容总结（100-150 字）： 生成式推荐（GR）将推荐重构为 next-token 生成问题，但现有 GR 流水线以语义为中心（Semantic ID），难以对齐 eCPM 等商业价值信号。UniVA 提出统一价值对齐框架：① 商业 SID 分词器：在 SID 构建阶段注入 eCPM 相关属性（出价、CVR 估计、广告主偏好），使 item representation 天然携带价值维度；② Generation-as-Ranking 解码器：联合监督学习（用户兴趣）和 eCPM 感知强化学习，在单次 SID 生成过程中同时完成生成与排序，无需额外排序层；③ 解决跨阶段价值信号丢失问题（tokenization → decoding → serving 三阶段统一对齐）。实验覆盖工业广告场景，与 GPR/OneRanker 等 GR baseline 对比验证。

业务价值与适配性： 可以让我们在广告生成式推荐系统中做到：在一次解码过程中同时优化用户相关性和广告主 ROI，避免"用户点击率高但广告主转化差"的分裂问题。可借鉴思路：eCPM-aware RL 对齐思路可直接集成到现有 GR 流水线（如类 GPR 架构）；商业 SID 分词器的"价值注入"方法论，也可用于改造传统 DIN/DIEN 的 item embedding 构建；暂需等待开源代码和生产 A/B 验证，当前为方法论阶段。

4. 【CR²：端云 LLM 推理路由新范式——无线延迟 + 能耗感知双约束下的 Cost-Risk 分层决策（上交 × 鹏城 × Meta）】

  • 评分：A/4 · I/3 · S=11 · P1 · 价值类型：成本优化/用户体验
  • 来源：上海交通大学 × 鹏城实验室 × Meta | arxiv.org/abs/2605.12001 | 2026-05-12

内容总结（100-150 字）： CR² 针对移动边缘（非数据中心）场景的 LLM 推理路由，将端云调度建模为带部署约束的 Cost-Risk 决策问题。两阶段框架：① 端侧 Margin Gate：轻量边界判断模块，冻结 query embedding + 用户指定 cost 权重，预测本地执行是否优于最佳边缘替代——延迟低，端侧零网络开销；② 边缘 Utility Selector：对延迟到边缘的请求做效用最优化选择，整合无线信道质量、当前能耗水位。相较纯 token-level 云端路由，CR² 显式建模无线传输延迟和设备续航约束，更贴近实际移动广告 SDK 部署环境。由上交、鹏城实验室、Meta AI 联合研究，方法在模拟无线环境中验证。

业务价值与适配性： 可以让我们在广告 SDK 的端云协同推理中做到：在无线网络不稳定（高延迟、弱信号）时自动保持端侧推理，减少因网络波动导致的请求超时或回退失败。可借鉴思路：Margin Gate 的轻量化设计可以直接作为广告 SDK 端侧模型调度器的参考实现；cost weight 参数化设计允许不同广告场景（竞价 vs. 展示）配置不同延迟/精度偏好；与 Firebase Hybrid Inference（5/22）的规则路由互补，本文提供了学习型路由的方法论基础。

5. 【HiSAC：多层级 SID + RQ-VAE + 层级投票稀疏激活——超长序列建模中的个性化兴趣压缩新框架】【延迟发酵】

  • 评分：A/4 · I/3 · S=11 · P1 · 价值类型：用户体验/成本优化
  • 来源：arXiv | arxiv.org/abs/2602.21009 | 2026-02-24（延迟发酵：首次收录，与本期 UxSID 构成超长序列建模方法论对照）

相较此前报道新增：本期为首次收录，2026-02-24 发表，近期在国内推荐社区（"从长序列到 Semantic ID"技术综述）随 SID 趋势升温而再度受关注。

内容总结（100-150 字）： HiSAC 解决超长序列建模中"聚类粒度不合适 → 量化误差大 → 长尾偏好丢失"的核心矛盾。方法：① 用大规模多模态编码器（文本 + 图像）+ 残差量化变分自编码器（RQ-VAE）将用户历史编码为多层级 Semantic ID；② 构建全局层级 Codebook，以层级投票（Hierarchical Voting）机制稀疏激活个性化兴趣 Agent；③ Agent 作为细粒度偏好中心，实现"item-specific 精度 + item-agnostic 效率"兼顾。相较 item-specific 逐条 attention，激活代价大幅降低；相较 item-agnostic 全局压缩，保留个性化长尾兴趣。在电商推荐场景验证，与 DIN/SIM/SDIM 等 baseline 对比提升显著。

业务价值与适配性： 可以让我们在广告用户行为序列建模中做到：以 RQ-VAE 压缩 + 稀疏激活替代全序列 attention，在保留低频/长尾用户兴趣的同时，将在线推理内存开销控制在可部署范围。可借鉴思路：与本期 UxSID（SID 路由 + 离线内存表）形成互补——HiSAC 强调"构建高质量 SID 压缩表示"，UxSID 强调"高效 O(1) 路由检索"，两者可串联成完整的"SID 压缩建模 + SID 路由检索"流水线；建议关注 RQ-VAE 的多模态编码部分，对视频素材理解 + 用户行为联合建模有直接参考价值。

其他观察

本期 5 篇文章呈现出 2026 年 5 月广告推荐技术的一个清晰主轴：Semantic ID（SID）正在成为连接"生成式推荐 × 用户行为建模 × 商业价值对齐"的统一语言。UxSID 用 SID 做 O(1) 路由，HiSAC 用 RQ-VAE 构建多层级 SID，UniVA 将 eCPM 注入 SID 分词器——三篇论文指向同一基础设施方向，说明国内工业推荐团队已在 SID 范式上形成技术共识；百度的 LLM 广告部署加速和上交/Meta 的端云路由，则从工程侧收紧了 LLM 进入实时广告系统的最后一公里。
