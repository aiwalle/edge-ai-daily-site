端智能日报 2026-06-19

本期聚焦：MobileMoE 将 Mixture-of-Experts 架构压缩至 0.9B 活跃参数并在 Galaxy S25 / iPhone 16 Pro 量产验证，给端侧广告多任务模型设计提供全新 Pareto 曲线；Apple Foundation Models 3rd Gen 公开 AFM 3 Core Advanced 完整架构（20B 稀疏 / 1-4B 活跃）并开源 CoreAILanguageModel，端侧 LLM 开发者生态进一步开放。

1. 【MobileMoE：端侧 MoE 架构新 Pareto 曲线——0.9B 活跃参数匹敌密集 LLM，decode 速度提升 2.2-3.4x，Galaxy S25 + iPhone 16 Pro 量产（arXiv 2605.27358）】

  • 评分：A/4 · I/4 · S=12 · P0 · 价值类型：成本优化 / 新能力探索
  • 来源：Meta AI 等 | arXiv 2605.27358 · HuggingFace 论文页 | 2026-05

内容总结（~150 字）： MobileMoE 提出一系列专为移动端设计的 Mixture-of-Experts 语言模型，活跃参数范围 0.3-0.9B，总参数 1.3-5.3B（稀疏激活）。核心贡献：① 14 个 benchmark 上以 2-4x 更少 FLOPs 匹配或超越同等内存预算的主流密集端侧 LLM（MobileLLM、Qwen3-0.6B 等）；② 推理速度：MobileMoE-S 相比密集基线 MobileLLM-Pro（INT4 等内存）prefill 快 1.8-3.8x，decode 快 2.2-3.4x；③ 量产验证：Samsung Galaxy S25（Snapdragon 8 Elite）和 iPhone 16 Pro（A18 Pro）通过 INT4 QAT + ExecuTorch 完整部署，是"首个在消费级手机上实现高效 MoE 推理"的工程落地成果；④ 同时达到或超越更大 MoE 模型 OLMoE-1B-7B，参数量减少 60%。

业务价值与适配性： 可以让我们在广告端侧多任务 LLM 中做到：① MoE 的"专家路由"天然匹配广告多任务需求——CTR 评分、用户意图分类、素材品质评估、对话广告应答可分别由不同专家承担，总参数预算（≤5B）不变但任务覆盖面扩大；② 2.2-3.4x decode 加速直接缩短广告 Agent 响应延迟，有望将端侧广告对话从 >1s 降至 <400ms；③ ExecuTorch 量产验证意味着 iOS + Android 统一部署路径今日可复用。适配性：今日可行动（P0）——建议以 MobileMoE 开源权重 + ExecuTorch 为基础，在 Snapdragon 8 Elite 开发板上做广告意图分类任务的 MoE PoC，对比 MobileLLM-Pro 密集模型的精度-延迟 trade-off。

2. 【Apple Foundation Models 3rd Gen：AFM 3 Core Advanced 20B 稀疏模型完整架构公开，CoreAILanguageModel 开源——端侧 AI 开发者平台进入"任意模型可部署"时代】【进展更新】

  • 评分：A/3 · I/5 · S=11 · P1 · 价值类型：新能力探索
  • 来源：Apple Machine Learning Research / 9to5Mac | Apple ML Research 原文 · 9to5Mac 解析 · GIGAZINE 工程细节 | 2026-06-08（发布）/ 2026-06-11（深度报道）
  • 相较 2026-06-15/06-18 报道新增：06-15 已覆盖 Python SDK + fm serve；06-18 已覆盖 Core AI 框架（替代 CoreML）；本条聚焦 AFM 3 完整五模型家族架构、20B 稀疏模型工程细节、CoreAILanguageModel + MLXLanguageModel 开源及多模态能力细节。

内容总结（~140 字）： Apple 在 WWDC 2026（6 月 8 日）发布第三代 Foundation Models，完整家族五款：端侧——AFM 3 Core（轻量）、AFM 3 Core Advanced（旗舰端侧，20B 参数稀疏架构，运行时激活 1-4B，原生多模态，可在 iPhone 16 Pro+ 上离线运行）；云侧——AFM 3 Cloud、ADM 3 Cloud（图像生成/编辑专用）、AFM 3 Cloud Pro（最强推理）。多模态能力：开发者可向端侧模型同时传入图像 + 文本，支持物体识别、OCR、截图分析，集成 Vision 框架工具。关键开放：CoreAILanguageModel + MLXLanguageModel 开源，允许开发者将任意第三方模型（Qwen、Llama 微调版等）直接运行在 Apple Neural Engine / Mac GPU 上，无需锁定 AFM 格式；小型开发者获免费 Private Cloud Compute 配额。

业务价值与适配性： 可以让我们在 iOS 广告 SDK 中做到：① CoreAILanguageModel 开源意味着广告团队可将内部微调的广告意图 LLM（如 Qwen3-0.6B INT4 广告意图分类版）直接接入 Apple Neural Engine，无需走苹果私有接口——iOS 广告端侧个性化 LLM 的集成路径首次完全打通；② AFM 3 Core Advanced 多模态能力支持广告素材图像 + 文案的本地联合质量评估（图文一致性 / 低质素材过滤），延迟在 ANE 上预计 <100ms；③ 免费 PCC 配额可用于广告 A/B 测试阶段的云侧 LLM 调用，降低试验成本。适配性：中期可行动——建议 iOS 广告 SDK 团队跟进 CoreAILanguageModel 开源仓库，优先评估广告 CTR 轻量模型在 ANE 上的迁移路径；多模态能力 PoC 可在 iPhone 16 Pro 设备上立即启动。

3. 【MNN 3.5.0 + 高通 NPU 加速 LLM：阿里端侧推理框架 NPU 路径工程解析——Prefill 全 NPU 执行，面向十亿级中国 Android 生态】

  • 评分：A/3 · I/3 · S=9 · P1 · 价值类型：成本优化
  • 来源：知乎技术博客 / Alibaba MNN GitHub | 知乎工程深度解析 · MNN GitHub Releases | 2026-04（v3.5.0 发布）/ 近期深度分析

内容总结（~130 字）： MNN 3.5.0（2026-04）正式加入 Qualcomm QNN NPU 后端 LLM 支持，填补此前 LLM 推理仅走 CPU/GPU 的路径缺口。近期知乎技术文章深度解析工程实现：① 模型导出：llmexport.py 支持将 HuggingFace 格式 LLM 一键转换为 MNN 可执行格式；② NPU 适配转换：激活值静态化（Static Activation Quantization）+ Hexagon 图优化，实现 Prefill 阶段全程 NPU 执行；③ 异构计算调度：Prefill（计算密集）→ NPU，Decode（内存密集）→ CPU 大核，针对移动 SoC 特性优化调度策略；④ 实测 Qwen2.5-1.5B INT4 在 Snapdragon 8 Gen 3 设备 Prefill 加速约 3-5x（vs GPU-only 基线）。MNN 广泛部署于淘宝、支付宝、钉钉及众多头部 App，是中国端侧 AI 最大生产分发路径。

业务价值与适配性： 可以让我们在 Android 广告 SDK 中做到：① 如果广告端侧意图分类模型（Qwen2.5-1.5B INT4）通过 MNN QNN 后端部署，Prefill 延迟可从 GPU 的 ~150ms 降至 NPU 的 ~30-50ms，满足广告实时请求 SLA；② MNN 的国内超大规模 App 生态覆盖意味着广告 SDK 通过 MNN 推理的集成阻力最低（无需额外引入 ExecuTorch / LiteRT，与宿主 App 共用推理框架）；③ llmexport.py 工具链可复用于广告微调模型的 MNN 格式转换，标准化内部模型导出流程。适配性：中期可行动——建议以 MNN 3.5.0 QNN 后端为目标，在 Snapdragon 8 Elite Gen 5 测试机上验证广告意图分类模型的 NPU Prefill 延迟，对比 ExecuTorch/LiteRT 基线，选最低集成成本路径。

4. 【LPDDR6 量产 H2 2026 在即：端侧 AI 内存带宽瓶颈的下一次拐点——SK Hynix 首发优化版本，旗舰 iPhone / Android 有望年内搭载】

  • 评分：A/2 · I/4 · S=8 · P2 · 价值类型：新能力探索
  • 来源：AndroidHeadlines / SK Hynix / JEDEC | AndroidHeadlines 最新报道 · JEDEC JESD209-6 标准 · SK Hynix on-device AI 版本 | 2026-06（最新行业进展）

内容总结（~130 字）： JEDEC 于 2025 年 7 月发布 JESD209-6（LPDDR6）标准，三星和 SK Hynix 均已完成开发认证，量产准备预计 2026H1 完成，出货 2026H2 开始。关键性能数据：基础速率 10.7 Gbps（比 LPDDR5X 快 33%），上限可达 14.4 Gbps；采用双子通道架构（Dual Sub-Channel），访问粒度 32B，有利于 LLM Decode 的内存密集型访问。SK Hynix 专门针对端侧 AI 优化的 LPDDR6 版本预计搭载于 Apple H2 旗舰产品（iPhone 17 Pro 系列），据行业研究机构预测需求将在 2026H2 随下一代旗舰集中爆发。工程背景：当前 Snapdragon 8 Elite Gen 5 + LPDDR5X 的内存带宽（~68-75 GB/s）已成为 LLM Decode 首要瓶颈；LPDDR6 切换后带宽可突破 100 GB/s，理论上线性提升 decode token/s。

业务价值与适配性： 可以让我们在广告端侧 LLM 规划中做到：① LPDDR6 旗舰手机 H2 2026 上市后，同等 LLM（如 Qwen3-1.7B INT4）的 decode 速度理论提升 30-40%，广告 Agent 对话响应将首次普遍满足 200ms 内 SLA；② 这是端侧广告 LLM 产品节奏规划的硬件锚点——建议将 H2 2026 旗舰发布时间纳入广告端侧 LLM 功能上线窗口评估。适配性：了解即可（P2）——LPDDR6 是硬件背景信息，短期无可行动点；但对 H2 产品路线图有规划参考价值。

其他观察

MoE 架构端侧化正成为 2026H2 的技术主线：MobileMoE 落地量产、MediaTek Dimensity 9500 原生支持 BitNet（另类稀疏），两项在不同技术路线上都指向同一结论——"以总参数换活跃参数"的稀疏/MoE 思路在端侧已经工程成熟，广告多任务模型的架构演进路线图需要将 MoE 纳入 2026H2 实验计划。Apple 端侧开发者平台加速开放：从 Python SDK（fm serve）→ Core AI 框架 → CoreAILanguageModel 开源，Apple 在 WWDC 2026 发布的端侧 AI 工具链已形成完整闭环；广告 SDK 在 iOS 上做端侧 LLM 的技术壁垒在本周进一步降低。
