端智能日报 2026-05-18

本期聚焦：Google I/O 2026 明日开幕（5/19），前夜两项开发者侧技术正式落地：① AppFunctions 将 Android 应用转化为"端侧 MCP Server"，广告 SDK 可首次将意图函数直接暴露给 Gemini Agent 本地调用；② AICore 隐私框架（Private Compute Core + Protected KVM）划定了端侧广告 AI 的数据合规红线——输入输出处理后不落盘、无直接网络访问。两项技术合力定义了"广告 SDK 参与 Gemini Agent 生态"的接入边界与合规路径。

1. 【Android AppFunctions："端侧 MCP Server" API 开放 Early Access，广告 SDK 可将用户意图函数直接暴露给 Gemini Agent】

  • 评分：A/4 · I/4 · S=12 · P0 · 价值类型：新能力探索 / 收入提升
  • 来源：Android Developers | AppFunctions Overview | Android Developers Blog | Building for the Intelligence System on Android | 2026-05-13

内容总结（~140 字）： AppFunctions 是 Android 16+ 的官方平台 API + Jetpack 库，允许 App 将自身能力暴露为 Gemini Agent 可调用的"端侧工具"——本质上是把 App 变成在设备上运行的 MCP Server。四步调用链：① App 用 @AppFunction 注解声明函数；② Jetpack 库生成 XML schema 注册至 OS 函数注册表；③ Gemini Agent 通过 AppFunctionManager 发现可用函数；④ 持有 EXECUTE_APP_FUNCTIONS 权限的 Agent 本地调用函数，全程不经网络。已有 25 个 App 参与 Private Preview（KakaoTalk、Uber、DoorDash），Early Access Program 注册通道现已开放（Google 审核后邮件通知）。覆盖：Android 16+（约 Pixel 9 / Galaxy S25 及以上起步）；Gemini 集成仍在私测，无公开 ETA。

业务价值与适配性： 可以让我们在广告 SDK 内将"用户当前意图信号获取"和"上下文相关广告触发"作为 AppFunction 暴露给 Gemini Agent，由 Agent 在用户完成跨 App 任务时主动调用广告 SDK 的推荐接口——实现广告由 Agent 主动分发而非用户被动浏览的新范式。可直接应用（Android 16+ 设备，短期接入复杂度低）：① 注册 AppFunctions EAP，以流媒体/音频 App 为主体暴露 get_user_content_preference()、suggest_premium_upgrade() 等函数；② 验证 Gemini Agent 在"播放音乐→推荐周边→触发广告"跨应用场景的 CTR 基线；③ 关注明日 Google I/O 是否宣布广告类 App 的接入白名单条件。限制：当前 Gemini 集成为私测，广告类 App 能否通过 EAP 审核需验证；数据访问受 EXECUTE_APP_FUNCTIONS 权限约束，不可越权读取用户数据。

2. 【Android Gemini Intelligence 安全隐私框架：AICore 输入输出不落盘 + Private Compute Core 划定端侧广告 AI 数据合规红线】

  • 评分：A/3 · I/4 · S=10 · P0 · 价值类型：用户体验 / 新能力探索
  • 来源：Google Security Blog | Android's Agentic Future: Building Gemini Intelligence on a Foundation of Security & Privacy | PrivacyGuides | Android Introduces New Privacy and Security Protections | 2026-05-13

内容总结（~135 字）： Google 发布 Gemini Intelligence 隐私安全框架，三大技术支柱：① AICore 数据隔离：每次推理请求独立处理，输入输出完成后立即清除，不存储任何推理记录；无直接网络访问，仅通过开源 Private Compute Services APK 间接访问互联网；② Private AI Compute：AICore 遵循 Private Compute Core 原则，restricted package binding 防止数据侧渠；③ Protected KVM：Agent 自动化任务时通过虚拟化隔离保护环境。用户侧新增：任务执行实时进度可见（"View progress"），屏幕顶部常驻通知 chip 不可隐藏；Android Privacy Dashboard 新增"过去 24 小时哪些 AI 助手触达了哪些 App"的审计视图。任务复杂度决定路由：简单+敏感任务走 Gemini Nano 本地，复杂任务走云端 Gemini。

业务价值与适配性： 可以让我们在设计端侧广告 AI 特性时明确合规边界——AICore 不落盘、无直接网络的约束意味着端侧广告推断结果不能被第三方 SDK 直接读取，每次推理结果用完即销毁，建立"推断→展示→清除"的合规流程。可借鉴思路：① 对标 AICore 的隐私框架，在广告 SDK 的端侧推理模块中实现"请求-执行-清除"三段式，避免推理结果跨次请求累积；② Privacy Dashboard 的 AI 活动审计视图意味着用户可看到广告 AI 何时何地访问了哪些 App，需确保广告 SDK 的 Agent 调用链经得起审计；③ Nano（简单任务）vs 云端（复杂任务）路由策略可直接借鉴到广告系统的"端云协同推断分级"设计中。暂不适用：Protected KVM 目前面向系统级 Agent，第三方广告 SDK 暂无直接访问路径。

3. 【Google I/O 2026 明日开幕（5/19）：Gemini 4 + Android 17 + XR 眼镜——端侧广告 AI 的 2026 H2 路线图即将落锤】

  • 评分：A/3 · I/4 · S=10 · P1 · 价值类型：趋势研判 / 新能力探索
  • 来源：Android Central | Google I/O 2026 Live Blog | Android Authority | What to Expect from Google I/O 2026 | 2026-05-18

内容总结（~130 字）： Google I/O 2026 主题演讲明日（5/19，北京时间 01:00）开幕。已披露/高度可信预期：① Gemini 4：更快推理、更强多步推理，云端旗舰模型，为 Hybrid Inference 路由的"云侧节点"提供升级；② Android 17 正式版：ModelManager API（Gemini Nano 向第三方开放）和 AppFunctions 从实验性升至 stable，开发者可在 Production 中部署；③ Android XR 智能眼镜（三星合作），首款 Android XR 消费级 AR 眼镜实物曝光，搭载 Gemini Live；④ Googlebook：Google 定义的新笔记本品类，为 Gemini Intelligence 专属优化，与 Android 手机深度同步；⑤ AppFunctions GA 时间线：预期宣布面向广泛开发者开放的条件和时间节点。硬件：覆盖最新 Pixel 9a（刚发布）和 Samsung Galaxy S26（预计 Q3）。

业务价值与适配性： 可以让我们在明日演讲后 2 小时内启动关键决策点快速评估：① ModelManager API 是否 stable（决定广告 SDK Android 模块端侧 LLM 接入的工程排期）；② AppFunctions GA 条件（决定广告 App 参与 Agent 分发生态的时间窗口）；③ Gemini 4 与 Hybrid Inference 路由的兼容性（影响云侧推理成本预测）。当前行动建议：明日主题演讲实时追踪（重点 Watch List：ModelManager stable API 文档、AppFunctions 广告类 App 白名单条件、Android 17 正式发布日期），5/20 午前输出"Google I/O 2026 端侧广告 AI 专项影响评估"。

4. 【百度文心5.1：超稀疏 MoE 训练成本降至业界 6%，Intel OpenVINO 支持端侧部署】

  • 评分：A/2 · I/3 · S=7 · P2 · 价值类型：成本优化
  • 来源：量子位 | 百度文心5.1发布 | MBA智库早报 | 百度文心5.1发布简报 | 2026-05-18

内容总结（~120 字）： 百度发布文心大模型 5.1，采用超稀疏 MoE 架构，总参数量约 0.8T（文心 5.0 的 1/3，后者约 2.4T），激活参数降至约 36B，预训练成本仅为业界同规模模型的 6%。登上 LMArena 国内搜索排行榜第一。工程亮点：依托"多维弹性预训练"技术，在同等算力下可训练更大规模稀疏模型；Intel OpenVINO 支持文心端侧模型在酷睿 Ultra 平台（PC/AI PC 级别，非手机）上本地部署；同时支持模型搜索、知识蒸馏、量化压缩的一站式小型化服务平台。部署注意：当前端侧版本为 PC 级（Core Ultra），移动端部署规格未公布；云端版本为主力，serving 成本优势明显。

业务价值与适配性： 可以让我们评估文心5.1作为广告 AI 推理服务器侧模型的成本可行性——同规模训练成本仅业界 6% 意味着百度系广告业务有更大空间用低成本模型服务 serving 端侧广告特征，间接降低云端推理总成本。暂不适用（广告端侧模块）：端侧部署目前仅限 PC AI 平台（非移动端），移动广告场景无法直接使用；且当前无 Android/iOS SDK；关注百度是否跟进发布移动端版本（鸿蒙/Android 适配）。可借鉴思路：超稀疏 MoE + 多维弹性预训练的训练方法论值得跟踪，看后续是否有端侧友好的小参数规格（如 3B/7B sparse MoE 版本）适合移动广告特征建模场景。
