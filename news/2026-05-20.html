端智能日报 2026-05-20

本期聚焦：Google I/O 2026 开发者日（Day 2）技术落地——LiteRT 在 Google I/O 正式宣布 Qualcomm + MediaTek 双厂商 NPU 加速器 GA，端侧推理框架完成"跨平台统一"最后一块拼图；同期 WebMCP 标准为浏览器端 AI 代理执行广告交互铺路，Antigravity 2.0 定义云端广告代理基础设施新范式。

1. 【LiteRT × Qualcomm + MediaTek 双 NPU 加速器正式 GA：100x CPU 提速，56 款模型 <5ms，端侧推理框架跨平台统一】【进展更新】

  • 评分：A3/5 · I4/5 · S=10 · P1 · 价值类型：成本优化 / 新能力探索
  • 来源：Google Developers Blog | Unlocking Peak Performance on Qualcomm NPU with LiteRT | MediaTek NPU and LiteRT | 2026-05-19（相较此前 LiteRT NPU 量产案例报道新增：双厂商同步 GA，I/O benchmark 数据首发）

内容总结（约 140 字）： Google 在 I/O 2026 同日发布 LiteRT QNN Accelerator（Qualcomm）与 LiteRT NeuroPilot Accelerator（MediaTek）双厂商正式版。Qualcomm 侧：替代旧版 TFLite QNN delegate，支持 90 条 LiteRT 算子，72 个标准 ML 模型中 64 个可完整委托 NPU；在 Snapdragon 8 Elite Gen 5 上，56+ 款模型推理延迟 <5ms（CPU 仅 13 款），FastVLM-0.5B prefill 达 11,000 tokens/sec；对比 CPU 提速 100x，对比 GPU 提速 10x。MediaTek 侧：NeuroPilot 在 Dimensity 设备上实现 12x CPU 提速，支持 Gemma 3（270M、1B、multimodal 3n E2B 变体）；与 Qualcomm 侧共用同一套 LiteRT API，开发者无需分平台维护。LiteRT 至此成为覆盖 Qualcomm + MediaTek 双主流 Android SoC 的统一推理框架。

业务价值与适配性： 1. 可以让我们在广告 SDK Android 模块中用一套 LiteRT 代码同时覆盖 Snapdragon 和 Dimensity 两条设备线，广告端侧意图分类（分类任务 <5ms）和素材 embedding 生成（轻量模型 <20ms）实现全量旗舰覆盖，无需额外维护。 2. 可直接应用（广告 SDK 推理模块）：① 优先评估 Gemma 3 1B 在 LiteRT NeuroPilot 上的用户意图标签抽取效果（MediaTek 机型占国内 Android 旗舰约 30%）；② 以 FastVLM-0.5B 探索素材多模态理解（11k tokens/sec prefill 满足实时广告请求链路延迟要求）；③ P1 立项：端侧 embedding 冷存储+LiteRT 热推理的混合方案，降低云端 embedding 服务调用成本。

2. 【Google I/O 2026 开发者主题演讲：Gemini 3.5 Flash + Antigravity 2.0 + Managed Agents，"代理基础设施"完整工具链落地】

  • 评分：A3/5 · I4/5 · S=10 · P1 · 价值类型：新能力探索
  • 来源：Google Developers Blog | All the news from the Google I/O 2026 Developer keynote | MarkTechPost | Google Launches Antigravity 2.0 | 2026-05-19

内容总结（约 140 字）： Google I/O 开发者演讲发布三项核心代理基础设施：① Gemini 3.5 Flash：首个"frontier intelligence + action"结合的代理模型，作为 Antigravity 工具链的默认推理核心；② Antigravity 2.0：独立桌面代理编排平台（+CLI + SDK），内置跨平台终端沙箱、凭证屏蔽、Git 策略硬化，定位 Claude Code 的正面竞品；③ Managed Agents API（Gemini API）：单次 API 调用即可获得含远程沙箱的完整代理实例，移除基础设施搭建摩擦。附加：Android CLI stable 发布，支持 AI 代理直接操作 Android Studio（语义符号解析、Compose 预览渲染、端到端 UI 测试 Journeys）；Android Studio Migration Agent 可在数小时内完成周级代码迁移任务。

业务价值与适配性： 1. 可以让我们用 Managed Agents API 在云端广告系统中快速构建"广告决策代理"——单次 API 调用即可启动带沙箱的广告策略优化代理，无需自建代理运行时基础设施，验证成本极低。 2. 可借鉴思路：Antigravity 2.0 的"沙箱化 + 凭证屏蔽 + Git 策略"三件套，可作为广告 AI 代理系统合规隔离方案的参考架构；Managed Agents 目前面向云端，端侧代理化能力尚待 AppFunctions GA 后才打通，暂不替代本地推理链路。

3. 【WebMCP：Chrome 将任意网页变成 AI 代理 MCP Server，Chrome 149 Origin Trial 正式开放】

  • 评分：A3/5 · I3/5 · S=9 · P1 · 价值类型：新能力探索
  • 来源：Chrome for Developers Blog | WebMCP is available for early preview | The New Stack | WebMCP turns any Chrome web page into an MCP server for AI agents | 2026-05-18~05-19

内容总结（约 130 字）： WebMCP 是 Google 提出的浏览器原生 MCP 标准，已在 Google I/O 放大曝光。核心机制：两套 API（声明式 HTML 表单 + 命令式 JavaScript），让网页直接向浏览器内置 AI 代理暴露结构化工具，全程纯客户端执行，无需额外后端 MCP 服务器；浏览器充当代理与网页之间的权限中介，复用用户已有的登录 session。时间线：Chrome 146（2026 年 2 月）上线早期预览；Microsoft Edge 147（3 月）跟进支持；Chrome 149 Origin Trial 5 月正式开放，目标成为 W3C 标准；对应 Android 侧 AppFunctions（端侧 MCP Server）构成"移动 App + 浏览器"双轨 AI 代理工具执行体系。

业务价值与适配性： 1. 可以让我们在流媒体 H5 广告落地页内声明 WebMCP 工具（如 subscribe_premium()、show_offer()），使用户浏览器内的 Gemini 代理在感知用户意图时主动调用广告转化动作——广告从"被动展示"演进为"代理主动触发"的新范式。 2. 可借鉴思路：近期评估 WebMCP Origin Trial 在 H5 广告落地页的技术可行性（声明式 API 接入成本极低，HTML 属性几行代码）；注意浏览器权限中介的限制——代理无法越权读取用户数据，广告 SDK 只能暴露用户主动同意的交互动作；实际广告规模化效果依赖 Gemini 在 Chrome 的集成进度（尚未 GA）。

4. 【Qualcomm Snapdragon 6 Gen 5 + 4 Gen 5 发布：AI 能力下沉中低端机型，H2 2026 量产】【延迟发酵】

  • 评分：A2/5 · I3/5 · S=7 · P2 · 价值类型：用户体验
  • 来源：Qualcomm | Qualcomm Unveils Two New Snapdragon Mobile Platforms | GSMArena | Snapdragon 6 Gen 5 and 4 Gen 5 announced | 2026-05-07

内容总结（约 120 字）： Qualcomm 于 5 月 7 日发布两款面向中低端市场的新 Snapdragon 平台。Snapdragon 6 Gen 5：AI 能力主要体现在相机侧（AI 夜视、AI 画质增强、100x 数字变焦）；App 启动速度较上代提升 20%，UI 卡顿减少 18%；首次支持 Wi-Fi 7、4K 视频录制。Snapdragon 4 Gen 5：面向更低价位段，同步引入 AI 相机能力。两款芯片均搭载 Hexagon NPU（具体 TOPS 未公布），Qualcomm AI Engine 支持本地模型推理。预计 H2 2026 首批搭载设备量产。意义：AI 推理硬件从旗舰（Snapdragon 8 Elite Gen 5，~15+ TOPS）向 6 系中端下沉，意味着具备基础 NPU 推理能力的 Android 设备覆盖范围将在 2027 年显著扩大。

业务价值与适配性： 1. 可以让我们在 2027 年广告策略分层中加入"中端 NPU 能力"分桶——Snapdragon 6 Gen 5 设备可运行轻量端侧分类模型（<1B 参数），但推理时延高于旗舰，需为这类设备设计更轻量的特征抽取方案（如 INT4 量化 + 50ms 延迟预算）。 2. 暂不适用（当前）：H2 2026 才量产，2027 年才有足够用户基数；现阶段广告端侧 AI 应优先聚焦旗舰机型（Snapdragon 8 Elite Gen 5 / Dimensity 9400）用户群。
